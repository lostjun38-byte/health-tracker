# 健康打卡 · 运动记录

一个**本地优先**的个人健康打卡与运动记录单页应用(Web App)。
所有数据只保存在你自己浏览器的 IndexedDB 里——没有后端、没有账号、没有埋点。

## 功能

| 页面 | 功能 |
|------|------|
| ✅ 今日打卡 | 饮水量快捷步进、睡眠时长、体重、步数、可选心情和备注；保存状态反馈、跨天草稿保护、连续打卡与最近 7 天日历 |
| 🏃 运动记录 | 9 种运动类型(快走/跑步/骑行/游泳/力量/瑜伽/球类/跳绳/其他)、时长、强度、按体重(MET 公式)自动估算热量;输入校验、筛选、编辑、删除、分页加载；补录和编辑后保持日期排序 |
| 📊 数据统计 | 最近 7/30 天的饮水、睡眠、运动时长柱状图,运动类型环形图,打卡率/日均饮水/日均睡眠/总消耗等阶段小结 |
| 🔒 隐私与数据 | 隐私说明、一键导出 JSON 备份(可选 AES-256-GCM 密码加密)、合并去重或覆盖恢复、完整校验与事务回滚、两步确认清空全部数据 |

## 视觉与交互

- **玻璃拟态(Glassmorphism)**:卡片、侧栏、底部导航均为半透明磨砂玻璃(`backdrop-filter`),悬浮在动态渐变背景之上。
- **动态背景**:三个大尺寸模糊光斑缓慢漂移(CSS keyframes),并随鼠标做惯性视差(rAF + lerp,只写 `transform`)。
- **鼠标交互**:卡片上有跟随光标的光晕(全局 `pointermove` 写入 CSS 变量),按钮/导航/心情等可点元素有涟漪反馈,卡片悬停上浮、图标微旋转。
- **动效**:指标数字滚动入场、柱状图逐根生长、今日打卡圆点脉冲、路由切换淡入上浮、名言切换过渡。
- **每日一句**:内置 28 条健康鼓励名言,按日期确定性选取,可点"换一句"本地轮换——依然零网络请求。
- **无障碍**：表单标签关联输入框，支持键盘操作、状态播报；`prefers-reduced-motion` 会关闭 CSS 动画和数字、背景的 JavaScript 动效。

## 运行

需要 **Node.js 24 或更新版本**。

```bash
npm ci
npm run dev       # 开发:http://localhost:5173
npm run build     # 构建到 dist/
npm run preview   # 本地预览构建产物
```

构建产物是纯静态文件(`dist/`),可部署到任意静态目录;使用 hash 路由,无需服务端回退配置。

## 数据可靠性与恢复

- 保存完成后才更新打卡状态；保存、删除或读取失败时显示原因并允许重试。
- 打卡跨天时自动切换到新日期。未保存的旧草稿会按日期在当前页面保留，可选择补存到原日期或放弃；离开页面前请先处理草稿。
- 备份在写入前检查版本、数组、日期、数值范围和记录字段。任一记录无效则整份拒绝，写入中途失败会回滚两张数据表。
- **合并去重**为默认方式：同日打卡保留 `updatedAt` 较新的记录；运动按日期、类型、时长、强度、热量和备注匹配，同一内容的记录次数取较大值。重复导入不会不断累加，也会保留备份中的多次相同运动。
- **覆盖恢复**在确认后替换当前全部记录；替换也在同一个事务中完成。
- 继续支持版本 1 备份及原有 PBKDF2 / AES-GCM 加密格式。加密采用分块 Base64 编码，避免记录较多时参数展开导致导出失败。
- 未填写的心情、睡眠、体重和步数以空值保存；真实的零步数、零小时睡眠会被保留。越界或无效输入会被拒绝，热量基于合法时长及运动日期当时最近的体重估算。

## 技术栈

- Vue 3(`<script setup>` 组合式 API)+ Vue Router 4
- Vite 6 构建
- 原生 IndexedDB 持久化(无 ORM)
- 原生 WebCrypto(PBKDF2 + AES-GCM)做备份加密
- 运行时依赖只有 `vue` 和 `vue-router` 两个包,图表为手写 SVG/CSS,零第三方图表库

## 数据隐私设计

1. **健康数据不出本机**：打卡与运动记录仅写入浏览器 IndexedDB，不发送到服务器；加载应用与切换页面时只请求站点自身的静态资源。无 CDN、无分析脚本、无字体外链。
2. **可携带**:JSON 一键导出/导入,换浏览器可迁移。
3. **加密备份**:导出可选 AES-256-GCM 加密,密钥由密码经 PBKDF2(SHA-256,15 万次迭代)派生;密码不出现在备份文件中,也不上传任何地方(因此忘记密码无法恢复)。
4. **可彻底删除**:两步确认即可清空本机全部数据。

## 性能设计

1. **极小产物**:本次构建全部 JS gzip 约 60KB，首屏 JS 约 51KB(其中 Vue runtime 占大头),四个页面代码分割、路由懒加载,首屏只加载打卡页。
2. **静态资源轻量**：无 CDN、无外部字体、无图片资源(图标使用系统 Emoji)，静态资源可由浏览器缓存。
3. **内存缓存 + 事务提交**：数据一次性读入响应式 store；写入走 IndexedDB 事务，提交成功后更新内存，避免显示未落库的数据。
4. **派生数据缓存**:连续天数、今日汇总、统计图表全部是 `computed`,只在依赖变化时重算。
5. **按需渲染**:历史记录列表分页渲染(每页 20 条,"加载更多"),统计页切换 7/30 天只重算数组;柱状图/环形图纯 div/SVG,无运行时图表开销。
6. **按需动效**：背景视差收敛后停止请求动画帧；页面进入后台或开启减少动态效果时暂停动画；卡片光晕按帧合并鼠标事件。

## 已知限制

- 清除浏览器"站点数据"会连带删除 IndexedDB 中的记录,请养成定期导出备份的习惯。
- 热量估算为 MET 简化公式(未计心率/海拔等)，仅供参考；强度作为记录标签，不额外改变 MET 系数。
- 数据存储遵循浏览器同源策略:换浏览器或换设备需通过"导出/导入"迁移。
