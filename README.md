# 健康打卡 · 运动记录

一个**本地优先**的个人健康打卡与运动记录单页应用(Web App)。
所有数据只保存在你自己浏览器的 IndexedDB 里——没有后端、没有账号、没有埋点。

## 功能

| 页面 | 功能 |
|------|------|
| ✅ 今日打卡 | 饮水量(+250/+500 快捷步进)、睡眠时长、体重、步数、心情、备注;连续打卡天数与最近 7 天打卡日历 |
| 🏃 运动记录 | 9 种运动类型(快走/跑步/骑行/游泳/力量/瑜伽/球类/跳绳/其他)、时长、强度、按体重(MET 公式)自动估算热量;筛选、编辑、删除、分页加载 |
| 📊 数据统计 | 最近 7/30 天的饮水、睡眠、运动时长柱状图,运动类型环形图,打卡率/日均饮水/日均睡眠/总消耗等阶段小结 |
| 🔒 隐私与数据 | 隐私说明、一键导出 JSON 备份(可选 AES-256-GCM 密码加密)、导入恢复、两步确认清空全部数据 |

## 视觉与交互

- **玻璃拟态(Glassmorphism)**:卡片、侧栏、底部导航均为半透明磨砂玻璃(`backdrop-filter`),悬浮在动态渐变背景之上。
- **动态背景**:三个大尺寸模糊光斑缓慢漂移(CSS keyframes),并随鼠标做惯性视差(rAF + lerp,只写 `transform`)。
- **鼠标交互**:卡片上有跟随光标的光晕(全局 `pointermove` 写入 CSS 变量),按钮/导航/心情等可点元素有涟漪反馈,卡片悬停上浮、图标微旋转。
- **动效**:指标数字滚动入场、柱状图逐根生长、今日打卡圆点脉冲、路由切换淡入上浮、名言切换过渡。
- **每日一句**:内置 28 条健康鼓励名言,按日期确定性选取,可点"换一句"本地轮换——依然零网络请求。
- **无障碍**:`prefers-reduced-motion` 下所有动画自动关闭。

## 运行

```bash
npm install
npm run dev       # 开发:http://localhost:5173
npm run build     # 构建到 dist/
npm run preview   # 本地预览构建产物
```

构建产物是纯静态文件(`dist/`),可部署到任意静态目录;使用 hash 路由,无需服务端回退配置。

## 技术栈

- Vue 3(`<script setup>` 组合式 API)+ Vue Router 4
- Vite 6 构建
- 原生 IndexedDB 持久化(无 ORM)
- 原生 WebCrypto(PBKDF2 + AES-GCM)做备份加密
- 运行时依赖只有 `vue` 和 `vue-router` 两个包,图表为手写 SVG/CSS,零第三方图表库

## 数据隐私设计

1. **数据不出本机**:打卡与运动记录仅写入浏览器 IndexedDB;应用加载完成后不发出任何网络请求,页面 `<meta name="referrer" content="no-referrer">`,无 CDN、无分析脚本、无字体外链。
2. **可携带**:JSON 一键导出/导入,换浏览器可迁移。
3. **加密备份**:导出可选 AES-256-GCM 加密,密钥由密码经 PBKDF2(SHA-256,15 万次迭代)派生;密码不出现在备份文件中,也不上传任何地方(因此忘记密码无法恢复)。
4. **可彻底删除**:两步确认即可清空本机全部数据。

## 性能设计

1. **极小产物**:构建后全部 JS gzip 约 43KB(其中 Vue runtime 占大头),四个页面代码分割、路由懒加载,首屏只加载打卡页。
2. **零网络请求**:无 CDN、无字体、无图片资源(图标全部使用系统 Emoji),二次打开基本瞬时可用。
3. **内存态 + 异步落库**:数据一次性读入响应式 store,所有页面渲染零查询延迟;写入走 IndexedDB 事务,不阻塞 UI。
4. **派生数据缓存**:连续天数、今日汇总、统计图表全部是 `computed`,只在依赖变化时重算。
5. **按需渲染**:历史记录列表分页渲染(每页 20 条,"加载更多"),统计页切换 7/30 天只重算数组;柱状图/环形图纯 div/SVG,无运行时图表开销。
6. **感知性能**:首屏骨架占位(index.html 内联)、路由过渡动画、列表增删过渡,均纯 CSS 实现。

## 目录结构

```
health-tracker/
├── index.html              # 入口,含首屏骨架样式
├── vite.config.js
└── src/
    ├── main.js             # 先加载本地数据再挂载,避免首屏闪空态
    ├── App.vue             # 侧栏(桌面)/顶栏+底部导航(移动)布局
    ├── router/index.js     # hash 路由 + 页面懒加载
    ├── lib/
    │   ├── db.js           # IndexedDB 封装(唯一持久层)
    │   └── utils.js        # 日期工具、MET 热量估算、运动类型表
    ├── stores/
    │   └── health.js       # 响应式 store:读写同步 + 派生数据
    ├── components/
    │   ├── StatCard.vue    # 概览指标卡
    │   ├── BarChart.vue    # 纯 CSS 柱状图
    │   └── DonutChart.vue  # SVG 环形图
    └── views/
        ├── DashboardView.vue  # 今日打卡
        ├── ExerciseView.vue   # 运动记录
        ├── StatsView.vue      # 数据统计
        └── SettingsView.vue   # 隐私与数据
```

## 已知限制

- 清除浏览器"站点数据"会连带删除 IndexedDB 中的记录,请养成定期导出备份的习惯。
- 热量估算为 MET 简化公式(未计心率/海拔等),仅供参考。
- 数据存储遵循浏览器同源策略:换浏览器或换设备需通过"导出/导入"迁移。
